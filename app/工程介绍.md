# Omi App 工程介绍

## 一、功能概述

Omi App 是一个基于 Flutter 开发的跨平台应用，作为 Omi 可穿戴设备的配套应用。该应用支持多种设备类型，提供音频录制、实时转录、对话管理、应用市场、记忆管理、任务集成等核心功能。

### 1.1 核心功能模块

#### 1.1.1 设备连接与管理
- **多设备支持**：支持 Omi、OpenGlass、Frame（智能眼镜）、Apple Watch、XOR、Bee、Fieldy、Friend Pendant、Plaud、AI Note 等多种设备类型
- **蓝牙连接**：通过 BLE（蓝牙低功耗）协议连接设备
- **设备发现**：自动扫描和发现附近的设备
- **连接状态管理**：实时监控设备连接状态，支持自动重连
- **设备信息获取**：电池电量、固件版本、设备特性等
- **固件更新**：支持 OTA（Over-The-Air）固件升级

#### 1.1.2 音频录制与处理
- **多源音频捕获**：
  - 设备音频流（通过 BLE 接收）
  - 手机麦克风录制
  - 桌面系统音频录制（macOS/Windows）
- **音频编解码**：支持 PCM16、PCM8、MuLaw、Opus、AAC 等多种音频格式
- **实时音频流处理**：低延迟音频数据传输和处理
- **后台录制**：支持应用后台运行时的音频录制
- **音频可视化**：波形显示、音频级别监控

#### 1.1.3 实时转录服务
- **WebSocket 连接**：与转录服务建立实时连接
- **流式转录**：音频数据实时上传并接收转录结果
- **多语言支持**：支持多种语言的语音识别
- **转录状态管理**：实时显示转录服务状态和进度
- **转录质量监控**：BLE 接收速率、WebSocket 发送速率等指标

#### 1.1.4 对话管理
- **对话创建**：自动或手动创建对话记录
- **对话列表**：按日期分组显示所有对话
- **对话搜索**：支持关键词搜索对话内容
- **对话详情**：查看完整转录、摘要、参与者等信息
- **对话处理状态**：处理中、已完成、已丢弃等状态管理
- **对话同步**：支持云端同步和本地存储（WAL 文件）

#### 1.1.5 应用市场
- **应用浏览**：浏览和发现可用的应用
- **应用安装**：安装应用到设备
- **应用管理**：查看已安装应用、更新、卸载
- **应用详情**：查看应用描述、评分、评论
- **应用创建**：开发者可以创建和发布应用

#### 1.1.6 记忆管理
- **记忆分类**：按类别组织和管理记忆
- **记忆回顾**：查看和回顾重要记忆
- **记忆搜索**：搜索特定记忆内容
- **记忆同步**：云端同步记忆数据

#### 1.1.7 任务集成
- **第三方任务平台集成**：
  - Todoist
  - Asana
  - Google Tasks
  - ClickUp
  - Apple Reminders
- **OAuth 认证**：支持第三方平台的 OAuth 登录
- **任务同步**：将对话中的行动项同步到任务平台
- **任务管理**：查看和管理同步的任务

#### 1.1.8 行动项（Action Items）
- **自动提取**：从对话中自动提取行动项
- **手动创建**：手动创建和管理行动项
- **提醒功能**：支持行动项提醒通知
- **任务关联**：将行动项同步到任务管理平台

#### 1.1.9 用户认证与配置
- **多种登录方式**：
  - Google 登录
  - Apple 登录
  - 自定义后端登录
- **用户资料管理**：姓名、头像、语言偏好等
- **语音配置文件**：训练和配置语音识别模型
- **订阅管理**：查看和管理订阅状态
- **使用统计**：查看使用量和配额

#### 1.1.10 其他功能
- **深链接支持**：支持应用内和外部链接跳转
- **推送通知**：Firebase Cloud Messaging 推送通知
- **数据隐私**：隐私设置和数据管理
- **开发者模式**：开发者工具和调试功能
- **支付集成**：Stripe、PayPal 支付支持

## 二、业务流程

### 2.1 应用启动流程

```
1. 应用初始化
   ├─ 环境配置加载（dev/prod）
   ├─ Firebase 初始化
   ├─ 服务管理器初始化
   ├─ 通知服务初始化
   ├─ 平台服务初始化
   └─ Provider 初始化

2. 认证检查
   ├─ 检查本地认证状态
   ├─ 如果已登录：加载用户数据、对话列表、应用列表
   └─ 如果未登录：显示登录页面

3. 路由决策
   ├─ 根据屏幕宽度选择移动端或桌面端界面
   └─ 根据认证状态和深链接跳转到相应页面
```

### 2.2 设备连接流程

```
1. 设备发现
   ├─ 启动蓝牙扫描
   ├─ 发现可用设备
   └─ 显示设备列表

2. 设备连接
   ├─ 选择目标设备
   ├─ 创建设备连接对象（根据设备类型）
   ├─ 建立传输层连接（BLE/Watch/Frame）
   ├─ 执行 Ping 测试验证连接
   ├─ 获取设备信息
   └─ 更新连接状态

3. 连接维护
   ├─ 定期 Ping 保持连接
   ├─ 监听连接状态变化
   ├─ 自动重连机制
   └─ 连接断开通知
```

### 2.3 音频捕获与转录流程

```
1. 开始录制
   ├─ 检查设备连接状态
   ├─ 检查网络连接
   ├─ 检查用户配额
   ├─ 启动音频源（设备/麦克风/系统音频）
   └─ 初始化转录 WebSocket 连接

2. 音频数据流
   ├─ 从设备/麦克风接收音频数据
   ├─ 音频格式转换（如需要）
   ├─ 通过 WebSocket 发送到转录服务
   └─ 实时接收转录结果

3. 转录处理
   ├─ 接收转录片段
   ├─ 更新对话内容
   ├─ 识别说话人（如支持）
   ├─ 实时显示转录文本
   └─ 保存到本地缓存

4. 停止录制
   ├─ 停止音频源
   ├─ 关闭 WebSocket 连接
   ├─ 创建对话记录
   ├─ 上传音频文件（如需要）
   └─ 触发对话后处理（摘要、行动项提取等）
```

### 2.4 对话处理流程

```
1. 对话创建
   ├─ 录制结束后自动创建
   └─ 或手动创建空对话

2. 对话后处理
   ├─ 音频上传到服务器
   ├─ 完整转录生成
   ├─ 对话摘要生成
   ├─ 行动项提取
   ├─ 参与者识别
   └─ 结构化数据提取

3. 对话同步
   ├─ 本地 WAL 文件保存
   ├─ 云端同步
   └─ 冲突解决

4. 对话查看
   ├─ 加载对话详情
   ├─ 显示转录内容
   ├─ 显示摘要和行动项
   └─ 支持编辑和分享
```

### 2.5 应用安装流程

```
1. 应用浏览
   ├─ 查看应用市场
   ├─ 搜索应用
   └─ 查看应用详情

2. 应用安装
   ├─ 选择目标设备
   ├─ 下载应用文件
   ├─ 通过 BLE 传输到设备
   ├─ 设备端安装
   └─ 验证安装状态

3. 应用管理
   ├─ 查看已安装应用
   ├─ 更新应用
   ├─ 卸载应用
   └─ 配置应用设置
```

### 2.6 任务集成流程

```
1. 平台连接
   ├─ 选择任务平台（Todoist/Asana/Google Tasks/ClickUp）
   ├─ 启动 OAuth 流程
   ├─ 用户授权
   ├─ 接收回调
   └─ 保存访问令牌

2. 任务同步
   ├─ 从对话中提取行动项
   ├─ 转换为任务格式
   ├─ 调用任务平台 API
   ├─ 创建任务
   └─ 更新同步状态

3. 任务管理
   ├─ 查看同步的任务
   ├─ 更新任务状态
   └─ 管理集成设置
```

### 2.7 用户认证流程

```
1. 登录
   ├─ 选择登录方式（Google/Apple/自定义）
   ├─ 执行 OAuth 流程
   ├─ 获取用户信息
   ├─ 保存认证令牌
   └─ 初始化用户数据

2. 会话管理
   ├─ 令牌自动刷新（5分钟缓冲）
   ├─ 令牌过期处理
   └─ 自动登出（令牌失效时）

3. 登出
   ├─ 清除本地数据
   ├─ Firebase 登出
   └─ 返回登录页面
```

### 3.2 核心模块详解

#### 3.2.1 后端层（Backend Layer）

**位置**：`lib/backend/`

**HTTP 模块** (`lib/backend/http/`)
- **shared.dart**：核心 HTTP 客户端
  - `ApiClient`：HTTP 客户端管理
  - `buildHeaders()`：统一请求头构建
  - `getAuthHeader()`：认证令牌管理（自动刷新）
  - `makeApiCall()`：统一 API 调用接口
- **api/**：各功能模块的 API 接口
  - `conversations.dart`：对话相关 API
  - 其他业务 API 接口
- **openai.dart**：OpenAI API 集成
- **webhooks.dart**：Webhook 处理

**Schema 模块** (`lib/backend/schema/`)
- 数据模型定义
- JSON 序列化/反序列化
- 类型安全的数据结构

**Preferences 模块** (`lib/backend/preferences.dart`)
- SharedPreferences 封装
- 本地数据持久化
- 用户配置管理

#### 3.2.2 服务层（Services Layer）

**位置**：`lib/services/`

**设备服务** (`lib/services/devices/`)
- **device_connection.dart**：
  - `DeviceConnectionFactory`：设备连接工厂
  - `DeviceConnection`：设备连接抽象基类
- **设备特定连接**：
  - `omi_connection.dart`：Omi 设备连接
  - `frame_connection.dart`：Frame 设备连接
  - `apple_watch_connection.dart`：Apple Watch 连接
  - `note_connection.dart`：AI Note 设备连接
  - 其他设备连接实现
- **传输层** (`transports/`)：
  - `ble_transport.dart`：BLE 传输实现
  - `watch_transport.dart`：Watch Connectivity 传输
  - `frame_transport.dart`：Frame 传输
  - `note_ble_transport.dart`：Note 设备 BLE 传输
- **设备发现** (`discovery/`)：
  - `device_locator.dart`：设备定位器
  - `bluetooth_discoverer.dart`：蓝牙设备发现
  - `apple_watch_discoverer.dart`：Apple Watch 发现

**Socket 服务** (`lib/services/sockets/`)
- **transcription_connection.dart**：转录服务 WebSocket 连接
- **wal_connection.dart**：WAL 同步 WebSocket 连接
- **pure_socket.dart**：通用 WebSocket 连接

**通知服务** (`lib/services/notifications/`)
- 推送通知处理
- 本地通知管理
- 通知权限管理

**WAL 服务** (`lib/services/wals.dart`)
- Write-Ahead Log 文件管理
- 对话数据本地存储
- 同步状态管理

**认证服务** (`lib/services/auth_service.dart`)
- Firebase Authentication 封装
- 令牌管理
- 用户会话管理

**其他服务**：
- `connectivity_service.dart`：网络连接状态监控
- `app_review_service.dart`：应用评分服务
- 任务集成服务（Todoist、Asana、Google Tasks、ClickUp）

#### 3.2.3 状态管理层（State Management Layer）

**位置**：`lib/providers/`

**基础 Provider**：
- **base_provider.dart**：所有 Provider 的基类

  - `setLoadingState()` 方法

**核心 Providers**：

1. **AuthenticationProvider**：用户认证状态
   - 登录/登出状态

2. **DeviceProvider**：设备连接状态
   - 当前连接的设备
   - 设备连接状态
   - 设备信息

3. **CaptureProvider**：音频捕获状态
   - 录制状态
   - 音频数据流
   - 转录连接状态
   - 录制时长、指标等

4. **ConversationProvider**：对话管理
   - 对话列表
   - 对话搜索
   - 对话分组
   - 对话处理状态

5. **MessageProvider**：消息管理
   - 应用消息列表
   - 消息缓存

6. **AppProvider**：应用市场
   - 应用列表
   - 已安装应用
   - 应用详情

7. **PeopleProvider**：人员管理
   - 对话参与者
   - 人员信息

8. **MemoriesProvider**：记忆管理
   - 记忆列表
   - 记忆分类

9. **ActionItemsProvider**：行动项管理
   - 行动项列表
   - 行动项状态

10. **TaskIntegrationProvider**：任务集成
    - 已连接的任务平台
    - 同步状态

11. **其他 Providers**：
    - `HomeProvider`：首页状态
    - `UsageProvider`：使用统计
    - `UserProvider`：用户信息
    - `SyncProvider`：同步状态
    - `SummaryProvider`：摘要生成
    - `SpeechProfileProvider`：语音配置
    - `OnboardingProvider`：引导流程
    - `NoteDeviceProvider`：Note 设备管理
    - `NoteOtaProvider`：Note 设备 OTA 更新

## 四、关键设计模式

### 4.1 Provider 模式
- 所有状态管理通过 Provider 实现
- BaseProvider 提供统一的加载状态管理
- 使用 ChangeNotifier 实现响应式更新

### 4.2 工厂模式
- `DeviceConnectionFactory`：根据设备类型创建相应的连接对象
- 支持多种设备类型的统一接口

### 4.3 策略模式
- 不同的传输层实现（BLE、Watch、Frame）
- 不同的音频源（设备、麦克风、系统音频）

### 4.4 观察者模式
- Provider 的 `notifyListeners()` 机制
- Stream 订阅机制（设备状态、音频流等）

### 4.5 单例模式
- `ServiceManager`：服务管理器单例
- `PlatformManager`：平台管理器单例
- `Logger`：日志管理器单例

## 五、数据流

### 5.1 音频数据流

```
设备/麦克风
    │
    ▼
音频数据 (PCM/Opus)
    │
    ▼
CaptureProvider
    │
    ├─► WebSocket ──► 转录服务 ──► 转录结果 ──► ConversationProvider
    │
    └─► 本地缓存 ──► WAL 文件 ──► 云端同步
```

### 5.2 设备通信流

```
UI Layer
    │
    ▼
DeviceProvider
    │
    ▼
DeviceConnection (抽象)
    │
    ▼
DeviceTransport (BLE/Watch/Frame)
    │
    ▼
物理设备
```

### 5.3 API 请求流

```
Provider/Service
    │
    ▼
buildHeaders() ──► 添加认证令牌
    │
    ▼
makeApiCall()
    │
    ├─► 401 错误 ──► 刷新令牌 ──► 重试
    │
    └─► 成功响应 ──► 解析数据 ──► 更新 Provider
```

## 十、总结

Omi App 是一个功能丰富、架构清晰的跨平台应用。通过模块化的设计、清晰的职责划分和良好的扩展性，支持多种设备类型和丰富的功能特性。采用 Provider 模式进行状态管理，通过服务层抽象实现设备通信，使用 Flutter 的跨平台能力实现移动端和桌面端的统一代码库。

主要特点：
- **多设备支持**：统一的设备连接抽象，支持多种设备类型
- **实时处理**：音频流式处理和实时转录
- **模块化架构**：清晰的分层和模块划分
- **跨平台**：一套代码支持多个平台
- **可扩展性**：易于添加新功能和设备支持
